# Data Sources and Licensing

**Status:** Verification note, 2026-11-28.
**Scope:** the public datasets used or proposed for the reliability audit.
**Not legal advice.** This records the published terms and the project's handling
rules; a commercial deployment needs its own legal review.

---

## 1. Decision

**The BAF suite is usable now for non-commercial research and portfolio work.**
It is **not** usable for a commercial pilot or a product claim without separate
permission.

| Question | Answer |
|---|---|
| Openly published? | **Yes** — public Kaggle release and official Feedzai repository |
| OSI “open source”? | **No** — this is data, not software. The dataset license is **CC BY-NC-SA 4.0**, which is openly licensed but **non-commercial** |
| Legal for this project? | **Yes, for non-commercial research**, with attribution and share-alike compliance |
| Legal for a commercial pilot? | **No, not under this license**; obtain permission or a commercial license |
| Contains PII? | **No PII in the released data**; it is synthetic, generated from anonymized data with privacy-preserving methods |
| Safe to redistribute? | **Do not redistribute raw files**; keep `data/` local and publish only aggregate results |
| Required attribution | Cite the BAF paper and the Kaggle dataset; retain the license notice |

The dataset and the repository are **separate licenses**: the code is Apache-2.0;
the dataset is CC BY-NC-SA 4.0. Do not cite the code license as the data license.

## 3. What the license allows

CC BY-NC-SA 4.0 allows sharing and adaptation for **non-commercial** purposes,
provided that you:

- give appropriate credit;
- link to the license;
- indicate changes;
- do not apply additional legal or technical restrictions;
- license adaptations under the same terms (share-alike).

It does **not** allow commercial use. “Non-commercial” is not a synonym for
“internal evaluation at a company”; if the work supports a commercial product or
pilot, treat it as commercial and get permission.

## 4. What this project does

- `data/` is git-ignored; raw BAF files are not redistributed.
- `reports/` contains aggregate metrics, not raw applicant rows.
- The case-study log is synthetic and generated by this project; it is not BAF
  data.
- The project cites the BAF paper and dataset in the paper and docs.
- No attempt is made to re-identify applicants, and no PII is present.

## 5. Verification gaps

1. **Version pin.** The current Kaggle release is version 2, but the project's
   `BENCHMARK_PROVENANCE.md` records a raw SHA-256 without naming the Kaggle
   version. Before a public release, record the Kaggle version and confirm the
   raw hash against that version.
2. **Index-label check.** Version 2 removed a relationship between the index and
   the label. The processed frame shows no material `transaction_id`-label signal
   (AUC about 0.512), but that is a check, not proof of the source version.
3. **Legal review.** This note is not legal advice. A commercial user must obtain
   permission from the dataset owner and review Kaggle’s terms.
