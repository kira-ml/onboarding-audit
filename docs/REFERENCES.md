# References

**Status:** Working bibliography for v0.2.1 (2026-11-20).
**Purpose:** Give the paper a single, checked citation list. The annotated review
is in the archived origin repository; this file is the public, curated subset.

**Verification rule:** A citation marked **verified** has a DOI, arXiv ID, or
proceedings page checked against a primary record. A citation marked **verify**
was used in the working notes but its final metadata (authors, pages, DOI) must
be checked before submission. Do not cite a **verify** entry in the paper without
checking it.

## 12. Citation rules for the paper

1. Every empirical claim about the literature has a citation from §1–§8.
2. Every regulatory claim has a citation from §9 and a date.
3. A **verify** entry is not cited until its metadata is checked.
4. Do not cite a preprint as peer-reviewed.
5. Do not cite the local archived path in a public document.
6. Keep the reference list consistent with this file; if a new source is added,
   add it here first.
