# Documentation Index

**Reading order for a reviewer (20 minutes):**

1. [`../README.md`](../README.md) — problem, quickstart, scope.
2. [`PROBLEM.md`](PROBLEM.md) — the evidence-backed problem brief.
3. [`PILOT_SPEC.md`](PILOT_SPEC.md) — the pre-registered estimand, DGP,
   estimators, scenarios, and kill criteria.
4. [`../reports/pilot.md`](../reports/pilot.md) — the generated pilot results.
5. [`CLAIMS.md`](CLAIMS.md) — the claim ledger.
6. [`THREATS.md`](THREATS.md) — the strongest counter-case and mitigations.

**For a practitioner:**

1. [`SCHEMA.md`](SCHEMA.md) — the decision-log schema.
2. [`AUDIT_DESIGN.md`](AUDIT_DESIGN.md) — the compliant audit design.
3. [`REPORT_USAGE.md`](REPORT_USAGE.md) — how to run and read the arbitrary-log report.
4. [`BSP_MAPPING.md`](BSP_MAPPING.md) — the regulatory mapping.
5. [`../configs/pilot.yaml`](../configs/pilot.yaml) — the pilot configuration.

**For a researcher:**

1. [`RELATED_WORK.md`](RELATED_WORK.md) — the gap map.
2. [`PILOT_SPEC.md`](PILOT_SPEC.md) — the pre-registration.
3. [`../paper/outline.md`](../paper/outline.md) — the paper structure.
4. [`../paper/brief.md`](../paper/brief.md) — the 2-page brief.
5. [`DECISIONS.md`](DECISIONS.md) — the decision journal.
6. [`WORKLOG.md`](WORKLOG.md) — the current state.

**For communication:**

1. [`ONE_PAGER.md`](ONE_PAGER.md) — the one-page reviewer brief.
2. [`COMMUNICATION.md`](COMMUNICATION.md) — the 60-second pitch, 10-minute
   walkthrough, five hard questions, and what not to claim.
3. [`GLOSSARY.md`](GLOSSARY.md) — terms.

**Data:**

1. [`DATA.md`](DATA.md) — the data card and limitations.

**Rule:** if a public sentence states a number, it must trace to
`reports/pilot.json` or a cited primary source. If it states a claim, it must
appear in `CLAIMS.md` or `PROBLEM.md`.
